# Sabiri Sport — Thème WordPress / WooCommerce

Thème e-commerce sombre et premium pour équipements sportifs (MMA, Boxe, Football, Rugby, CrossFit, Médailles & Trophées). 100% en français, optimisé mobile et desktop.

## 📦 Installation

1. **Téléchargez le thème en ZIP** : compressez le dossier `sabiri-sport/` (le dossier lui-même, pas son contenu) en `sabiri-sport.zip`.
2. Dans WordPress : **Apparence → Thèmes → Ajouter → Téléverser un thème** → choisissez le ZIP → **Installer** → **Activer**.
3. Installez et activez le plugin **WooCommerce** (Extensions → Ajouter) si ce n'est pas déjà fait, puis suivez l'assistant de configuration.

## ⚙️ Configuration recommandée

### 1. Page d'accueil
- Créez une page « Accueil » (vide, le thème gère tout).
- **Réglages → Lecture** → « Une page statique » → page d'accueil = « Accueil ».

### 2. Menus
- **Apparence → Menus** : créez un menu (Accueil, Boutique, Sports de combat, Football, CrossFit, Contact…) et assignez-le à l'emplacement **Menu principal**. Idem pour le **Menu pied de page**.

### 3. Catégories de produits
- **Produits → Catégories** : créez vos 6 catégories principales (MMA & UFC, Boxe & Kickboxing, Football, Rugby, CrossFit & Fitness, Médailles & Trophées) **et ajoutez une image (miniature) à chacune** — elles s'affichent automatiquement sur l'accueil.

### 4. Produits phares
- Dans **Produits**, cliquez sur l'étoile ⭐ (colonne « Mis en avant ») pour les produits à afficher dans la section « Produits phares » de l'accueil (6 max).

### 5. Personnalisation (textes, hero, contacts, réseaux)
- **Apparence → Personnaliser → Section Hero (Accueil)** :
  - Textes du hero (titre, sous-titre, image de fond)
  - Numéro **WhatsApp** (format : `212612345678`) → active le bouton flottant vert
  - Liens Instagram / Facebook / TikTok
  - Téléphone, email, adresse (affichés dans le footer)
- **Apparence → Personnaliser → Identité du site** : logo.

### 6. Paiement à la livraison
- **WooCommerce → Réglages → Paiements** → activez « Paiement à la livraison ».

## 🚀 Optimisation (fortement recommandé)

- **Cache** : installez *LiteSpeed Cache* ou *WP Super Cache*.
- **Images** : installez *Smush* ou *ShortPixel* pour compresser les images (les images du thème sont déjà en lazy-loading).
- **SEO** : installez *Rank Math* ou *Yoast SEO*.
